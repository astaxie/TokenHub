# 分离上游成本与租户费用，以通用规则承载供应商计价

供应商的峰谷和缓存优惠影响 TokenHub 的上游成本，而租户费用由独立收费规则决定。2026-09-05 设计访谈确认分别建模这两类费用，避免将供应商调价直接等同于租户调价。第二轮进一步确认租户采用独立价目，可配置各用量分项及峰谷价格。

首期使用通用计价规则模型，以 DeepSeek 的峰谷与缓存用量为首个验证案例。范围包含供应商报告的缓存读写计量计价，网关响应缓存独立设计。相比 DeepSeek 专用分支，这要求明确通用计费分项与供应商映射，但能避免后续接入不同缓存有效期和时段规则时重新定义账目语义。

首期接入现有费用归集与预算控制，不新增充值钱包。原币与版本策略见 [ADR-0010](0010-preserve-billing-price-and-currency-evidence.md)，预留和重试归属见 [ADR-0011](0011-reserve-budget-and-separate-attempt-costs.md)。价格由管理员确认发布，公开目录变化只生成候选变更；本期不新增低谷排队、按时段自动切换供应商或缓存亲和路由。现有路由对价格的依赖仍须保留并验证。这些决策不代表实现完成。讨论与证据见[访谈记录](../discussions/2026-09-05-time-cache-billing.md)。
