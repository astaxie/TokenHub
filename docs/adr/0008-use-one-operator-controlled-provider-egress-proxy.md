# 使用一个由平台管理员控制的 Provider 出站代理

TokenHub 对全部 Provider 上游请求采用统一的出站模式：继承进程环境、明确直连，或使用系统设置中的单一 HTTP/HTTPS 代理。代理路径把最终目标的解析和访问策略交给平台管理员，不执行直连地址检查；直连路径继续执行 Provider 上游 SSRF 防护。代理不可用、配置不可解密或尚未成功加载时请求失败，不隐式回退直连，因为回退会绕过管理员选择的出口和审计边界。

代理连接、认证和代理超时属于平台出站故障，不计入单个 Provider Resource 的失败次数，也不触发资源冷却。配置通过共享数据库传播到全部实例，短暂读取失败时使用最后有效配置；历史 `proxies` 资源不参与优先级，也不改变升级后默认继承标准环境代理变量的行为。
