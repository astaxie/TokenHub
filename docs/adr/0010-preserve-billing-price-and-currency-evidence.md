# 保留原币与定价版本，通过调整记录修正历史费用

供应商价格、计费时段和汇率都会变化，仅保存折算金额或结算时读取最新配置，不能稳定解释费用来源。2026-09-05 第二轮设计访谈确认保留上游原币金额，另记折算金额与汇率依据；价格以带生效时间的版本发布，请求固定已选定价依据，历史费用保留原记录，纠错通过可追溯的调整记录表达。

相比覆盖价格与重写历史金额，这会增加版本和对账管理成本，但能解释供应商调价、汇率变动及账单差异。租户价目与供应商价目分别生效，不因供应商调价而自动改变租户收费。供应商跨时段计价依据未确认时必须保留不确定性，不能将平台的租户定价时点当作供应商已确认规则。

第三轮进一步确认首期租户价目及预算保持 USD，上游保留原币；由管理员发布带生效时间的汇率版本。第四轮确认每次上游尝试在发送时锁定适用汇率，缺汇率时成本折算待定，USD 租户预算独立执行；价格、汇率及调整由获授权管理员操作并审计，普通用户只查看授权范围内的用量和租户费用。

历史记录不追溯重算，也不补造价格版本或缓存分项；新计价经影子计算与对账验证后从明确切换时间启用。缺价与免费必须区分，基础必需租户价格缺失不得发布，上游缺价保持成本未知。估算费用遵循 [ADR-0011](0011-reserve-budget-and-separate-attempt-costs.md)，完整方案见[设计稿](../discussions/2026-09-05-time-cache-billing-design.md)。
