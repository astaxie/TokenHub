# 模型调价与平台账单

## 模型调价

平台管理员在“模型目录 → 定价与收益”打开采用 Token 计价的聊天或 Embedding 模型，直接修改全局输入、输出、缓存价格及分时规则。历史收益分析和高级单请求试算均为可选步骤。

1. 编辑价格；普通模型资料编辑不会覆盖 Token 价格。
2. 可选展开历史收益分析，选择日期、时区、项目及成本口径。项目只筛选分析样本，保存的模型价格仍全局生效。
3. 点击“核对并保存”，检查新旧价格、亏损、未知证据或未分析提示，并勾选风险确认。
4. 确认后保存，取消不写入。新请求立即使用新价，在途请求继续使用准入时的配置。

分析默认最近 30 个完整日，不含今天；提供最近 7 日快捷选择，自选范围最多 93 天。日期按选定的 IANA 时区解释。请求按准入日期归集，跨日重试也纳入固定分析截止时刻的证据；明细超过 10000 条报错并要求缩小范围，不抽样或静默截断。

结果区分历史实际收费、现价重算和候选价重算。历史成本采用已保存的尝试成本估算；当前采购价情景使用当前库存价格，在原请求时间、实际路由、缓存分布和重试次数上重新计算，并非未来预测。规则的绝对生效日期保持原样，未被样本命中的规则单独提示。每请求只计一次收入，成本包含所有尝试，按 Provider/资源账号组合展示毛利。

可计算样本不代表供应商已核实。请求覆盖率与已知历史收费金额覆盖率分列，未知收费另计；分母为零不显示百分比。存在缺失证据时不提供整体毛利，只展示可计算子集，不外推。亏损、未知或未分析可以在明确确认后保存。模型价格变化使确认失效；当前采购价依据变化使分析凭据失效。同一调价请求重发不会重复应用或记录审计。

缓存读价留空使用模型原有默认估算规则，缓存写价留空使用默认输入/写入价格，填写 `0` 表示明确免费。Provider 的输入、输出及缓存读价支持区分未配置和明确免费；在 Provider 模型库存保存空字段表示未知，填写 `0` 表示免费。未知成本不会用下游收费代替。重新导入已有 Provider 模型只刷新目录信息，保留已保存价格、分时规则及价格配置状态；需要调价时在模型库存明确编辑。

分时规则支持星期（0 为周日，6 为周六）、IANA 时区、起含止不含的时间区间，以及输入、缓存读写和输出覆盖。跨午夜按开始日计算，时段不能重叠，最多 64 个。试算时间显示浏览器本地时区；各时段使用自身时区匹配。Embedding 不支持分时规则。

“调价记录”仅展示实际生效的变更，保留模型、操作者、时间、新旧配置及默认规则对应的价格依据，最多读取最近 100 条。独立影子价目发布流程已退出；`/api/admin/billing/rate-cards` 返回 410。不会删除既有证据或重算历史费用。

实际调价还保留分析摘要与成本口径，或明确记录未分析。草稿与每次分析不会保存为价格版本。

用量证据独立于价格采集。请求详情和调价历史展示上报、推导、估算、缺失、无效及旧记录未验证的字段状态、明确零值、流完成状态和各次尝试。供应商调用 ID、响应 ID 和链路 ID 分开记录，本地请求 ID 不能替代供应商 ID。外部对账只比较金额：“金额已匹配”不代表 Token 字段语义一致。

## 平台账单

“成本账单 → 平台账单”不需要配置账单连接器。选择月份对应的起止日期或自选范围，分别查看下游收费和上游成本估算，可按 Provider、资源账号、模型或项目汇总，查看分页明细并导出 CSV。

- 下游金额来自已结算的实际平台收费，按请求准入时间归集。失败或部分交付请求已经计入的费用仍须列入；不因平台重试重复计费。
- 上游金额按每次上游尝试及当时保存的价格、用量计算，包括重试。缺价、缺用量、尚未完成或缺少折算依据的记录显示待核实。
- 已知小计只包含已知金额；存在待核实或历史依据不足的记录时，明确标为不完整，不冒充供应商确认的成本。
- 历史记录只使用已保存的金额和身份信息，不用当前价格追溯补算。
- 页面汇总、明细、对账使用共同的账单证据投影。单次最多 10000 条，超限返回错误，需缩小范围或增加筛选，不静默截断。平台查询范围最多 366 天；客户/供应商独立对账单保留 93 天范围限制。

“平台账单”中的“客户对账单与毛利”保留现有的客户/供应商明细预览；模型目录和 Provider 库存也可打开对应对账单。该视图要求明确客户项目范围，导出当前预览快照，并将供应商金额与本地估算分列，不相加。

“外部对账”用于连接器账单与本地上游成本比较。连接器不是平台估算出单的前提。上游成本未知时不能按零或下游收费执行对账，须先补齐依据；明确免费的上游成本可以按零比较。本期不新增平台账单锁账、PDF 或手工外部账单导入。

## 管理接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/admin/billing/models/{model}/pricing` | 获取当前模型计价配置及并发校验指纹 |
| POST | `/api/admin/billing/model-pricing/check` | 不依赖试算用量校验价格 |
| POST | `/api/admin/billing/model-pricing/impact` | 分析 `{card, fingerprint, basis, from, to, timezone, project_ids}` 并返回确认凭据 |
| POST | `/api/admin/billing/preview` | 试算 `{card, usage, at, exchange_rate?}`；租户试算复用实际计费逻辑 |
| POST | `/api/admin/billing/model-pricing/apply` | 确认应用 `{card, fingerprint, request_id, confirmed:true, risk_acknowledged:true, analysis_receipt?}` |
| GET | `/api/admin/billing/price-changes` | 最近实际调价记录 |
| GET | `/api/admin/billing/statements` | `kind=tenant/provider`、RFC3339 `from/to`、筛选、分组和分页；`format=csv` 导出 |
| POST | `/api/admin/billing/statements` | 现有客户/供应商/毛利对账单预览 |
| GET | `/api/admin/billing/evidence/{request_id}` | 请求与上游尝试的原始费用证据 |

这些接口仅对平台管理员开放。调价的实际价格配置与变更记录在同一事务保存；CSV 中不包含凭据、提示词或响应正文，并转义公式前缀。现有结构版本 4 足够承载记录，不修改历史迁移。请求费用证据会继续积累，当前没有自动保留期限清理。
