# Triage Labels

スキルの標準ロールを以下の GitHub ラベルに対応付けます。

| 標準ロール | リポジトリのラベル | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | メンテナーの評価待ち |
| needs-info | needs-info | 報告者からの追加情報待ち |
| ready-for-agent | ready-for-agent | 仕様が揃い、Agent による実装が可能 |
| ready-for-human | ready-for-human | 人による実装が必要 |
| wontfix | wontfix | 対応しない |

スキルが状態ロールに言及した場合は、表の対応するラベルを使用します。
既存の命名に合わせる場合は、リポジトリのラベル列を直接編集できます。
